# Basic To-Do App

## What This Is

A simple to-do application with a basic frontend and straightforward backend. Users can create, view, complete, and delete tasks. Built for quick utility — no unnecessary complexity.

## Core Value

Users can manage their tasks through a clean, functional interface that works reliably.

- [ ] User can view all tasks in a list
- [ ] User can mark a task as complete
- [ ] User can delete a task
- [ ] Tasks persist between page refreshes

### Out of Scope

- User accounts / authentication — basic app, single user or shared state
- Collaboration features — not needed for a basic to-do app
- Mobile native app — web-first

## Context

- Project goal is "basic" — simple, functional, no over-engineering
- Both frontend and backend are in scope (full-stack)
- No specific tech stack dictated; standard web technologies apply

## Constraints

- **Scope**: Keep it simple — basic frontend, basic backend, core CRUD only
- **Complexity**: No authentication, no multi-user, no real-time sync for v1
