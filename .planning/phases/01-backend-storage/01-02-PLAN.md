Create `db.js` at the project root. This module opens the SQLite database, runs the schema DDL, and exports the `db` connection. It must follow the startup sequence from TechArch Appendix A exactly.

**Implementation requirements:**

1. Load `dotenv` so `DATABASE_URL` is available from `.env`
2. Read `DATABASE_URL` from `process.env`, defaulting to `./data/todo.db`
3. Ensure the `data/` directory exists before opening the DB file (use `fs.mkdirSync` with `{ recursive: true }`)
4. Open the SQLite connection using `better-sqlite3`. Wrap in try/catch:
   - On failure: `console.error("FATAL: Cannot connect to storage. Exiting.")` then `process.exit(1)`
5. Run the EXACT DDL from TechArch §3.2 (copy verbatim):

```sql
CREATE TABLE IF NOT EXISTS tasks (
    id          INTEGER       PRIMARY KEY AUTOINCREMENT,
    title       VARCHAR(500)  NOT NULL,
    completed   BOOLEAN       NOT NULL DEFAULT FALSE,
    created_at  DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_tasks_created_at
    ON tasks (created_at ASC);
```

   Wrap in try/catch:
   - On failure: `console.error("FATAL: Schema init failed. Exiting.")` then `process.exit(1)`

6. Export `db` as `module.exports = db`

**Complete implementation:**

```javascript
"use strict";

const path = require("path");
const fs = require("fs");
require("dotenv").config();
const Database = require("better-sqlite3");

const dbPath = process.env.DATABASE_URL || "./data/todo.db";

// Ensure the directory exists before opening the file
fs.mkdirSync(path.dirname(path.resolve(dbPath)), { recursive: true });

let db;

try {
  db = new Database(dbPath);
} catch (err) {
  console.error("FATAL: Cannot connect to storage. Exiting.");
  console.error(err.message);
  process.exit(1);
}

try {
  db.exec(`
    CREATE TABLE IF NOT EXISTS tasks (
        id          INTEGER       PRIMARY KEY AUTOINCREMENT,
        title       VARCHAR(500)  NOT NULL,
        completed   BOOLEAN       NOT NULL DEFAULT FALSE,
        created_at  DATETIME      NOT NULL DEFAULT CURRENT_TIMESTAMP
    );

    CREATE INDEX IF NOT EXISTS idx_tasks_created_at
        ON tasks (created_at ASC);
  `);
} catch (err) {
  console.error("FATAL: Schema init failed. Exiting.");
  console.error(err.message);
  process.exit(1);
}

module.exports = db;
```

**Important notes:**
- Use `"use strict"` at the top
- The module uses synchronous `better-sqlite3` API throughout — no async/await needed
- `db.exec()` runs multi-statement SQL; the CREATE TABLE and CREATE INDEX can be in one call
- Do NOT use `db.prepare().run()` for DDL — `db.exec()` is correct for schema statements
- The exported `db` is a live `Database` instance ready for `.prepare().get()`, `.prepare().all()`, `.prepare().run()` calls
